# EnvFoundry · Physics-Grounded Synthetic Lab

**面向人和 AI Agent 的开放实验室 · 项目宗旨与长期建设标准**  
2026 年 11 月 24 日。项目以 `EnvFoundry/Synthetic-Lab` 建立。本文描述长期宗旨和领域协作标准，当前可运行能力及待完成工作见 [开发路线](roadmap.md)。Agentic 描述实验者根据观测自主决策的研究方式，Digital Twin 用于持续对应具体实物的装置。

## 一、项目要交付什么

建设一套可在本地或云端运行的实验室系统。研究者与 AI Agent 可以带着一个尚无答案的问题进入，查看可用仪器和材料，搭建或改造装置，制备试样，安排对照，采集原始观测，分析结果，再决定下一步。一次操作的物理后果留在现场。第二天回来，研究可以从昨天那份样品、那套装置和那批数据继续。

仓库交付一套运行实验的公共软件、一组可以实际操作的参考实验室，以及其他团队接入自己的装置、模型和测量数据所需的接口和实例。首要用户是做实验的人和 Agent。他们可以研究现象的成因，也可以设计一种器件、一种工艺或一种新的测量方法。领域专家可以发布实验室，模型与 Harness 开发者可以用同一实验室采集数据、训练和比较策略。

建设这个项目有三个目的。第一，让原本需要等待机时或耗费样品的研究，可以先探索许多实验设计，再把实物用在能改变判断的测量上。第二，让一个团队在几年中积累的装置、标定和实验方法，能够被另一个团队复用、质疑和改进。第三，让不同模型与 Agent 在相同的实验条件下学习和比较。三个目的分别看研究问题能否回答、他人能否接手、方法能否在独立工况上工作。

一套实验室可以有几种使用方式。**虚拟实验室**让用户用软件操作一套持续存在的装置。**合成实验室**按物理约束生成不同个体、初始条件和工作环境，适合研究者探索尚未制造的设计，也适合并行训练。**数字孪生**对应有身份的实体装置，随实测数据更新，并记录校准时间和适用范围。**云端**负责远程访问、持续运行和并行实例。连接远程真机时，每次操作与读数还要指明具体设备。一个项目可以同时支持这些形式。

## 二、为什么需要一间能改变的实验室

考虑一只带温度计的发热电阻。重新装夹后，温升明显增加。研究者想知道是耗散功率增大了，还是散热变差了。在环境温度稳定、近似单一热阻且已达稳态的条件下，有

$$
T_\mathrm{s}-T_\mathrm{amb}=P\,R_\mathrm{th}.
$$

温度计读得再准，单个稳态温升也只约束乘积。Agent 可以自己给加热元件接入电压、电流测量，以实际耗散功率为横轴，在几个稳态点估计热阻。它也可以改动装夹条件，提前预测哪一条曲线会改变，再做实验。此时，加一条测量通道改变了它能够回答的问题。它也可能发现一条直线解释不了换装后的曲线，从而转向研究接触或对流条件。

**一间可用于发现的实验室，允许研究者改变获得知识的条件。** 每增加一条测量通道、一种样品处理方法或一种可控扰动，都可能使原本分辨不开的解释产生不同预测。实验室应支持这些组合，容许作者没有预写过的问题和实验程序。在已建模的物理范围内，新实验可以由已有部件组成。需要新的物理机制时，领域团队可以增加模型，并用新的实测观测检验它。

## 三、一间实验室由什么构成

| 组成 | 需要表达的内容 | 对实验者意味着什么 |
|---|---|---|
| 实验对象与装置 | 样品、系统或过程的身份和状态，仪器、连接方式、边界条件与可调参数 | 可以换仪器、改变连接、转移同一样品，也可以在原配置上做对照 |
| 操作与实验时间 | 制备、激励、改变条件、观测、等待和外部事件，各自的持续时间、可行范围与资源消耗 | 动作有先后、并行和不可逆后果。在等待的几分钟里，系统仍可能升温、漂移或老化 |
| 动力学与测量 | 领域模型推进对象与设备的状态，传感器根据量程、带宽、校准、采样及噪声形成读数 | Agent 得到实际可用的图像、波形、光谱或事件。一个共同扰动可同时反映在多台仪器上 |
| 实验现场与记录 | 装置配置、样品历史、实验时钟、尚未结束的过程、模型版本、原始观测及操作记录 | 可以接续长期研究。在支持完整恢复的模拟器中，还可以从同一现场分出不同实验路线 |

可用一个简短的关系描述这四项如何工作。设 $s_k$ 为第 $k$ 次决策时的现场，$a_k$ 为实验者选择的操作，$M$ 为当前装置和过程模型。一次操作产生

$$
(s_{k+1},\ o_{k+1},\ \Delta t_k)\ \sim\ K_M(\,\cdot\mid s_k,a_k\,).
$$

$o_{k+1}$ 是仪器实际提供的观测，$\Delta t_k$ 是经过的实验时间。测量动作也可能改变 $s_{k+1}$，例如取样减少剩余材料、探头改变电路负载。Agent 通过仪器取得可测的读数，读数由当前模型或实物产生。研究目标、假设和下一步决策属于实验者。

**同一现场可以有四种用法。** 开放科研允许 Agent 自定对照、探索新问题，按科学需要结束。评测为不同 Agent 提供等价的未知装置和预算，另用保留观测比较判断。强化学习并行启动独立模拟实例，由任务包给出奖励和终止条件。数据工程保留操作、结果、原始数据及其来源，按装置个体、样品批次或日期划分训练与评测。一次研究过程中有价值的未计分尝试同样可以保留。

## 四、怎样兼顾通用性与物理深度

通用部分是对象、操作、观测、时间和现场的延续。每个领域决定哪些量要守恒、哪些过程有记忆、什么能观测、什么能操纵、哪些近似成立。跨设备连接时，传递带单位、时间和参考条件的物理量、样品或数据。多个组件同时影响同一过程时，由该领域的耦合模型决定推进方式。

| 领域示例 | 值得长期操作的对象 | 可开展的研究 |
|---|---|---|
| 光学与光子学 | 光路、光纤耦合、样品、参考支路、探测器 | 功率下降源于光源变化还是耦合漂移？增加哪条观测最能分辨？ |
| 半导体与材料 | 同一片样品的沉积、退火、表征和环境循环历史 | 前几层出现厚度偏差后，能否根据实测光谱调整后续工序，挽回器件性能？ |
| 电池与能源 | 电芯的充放电历史、温度、极化和老化 | 两只端电压相近的电芯，下一次加载后的响应是否相同？哪种短测量最有预测力？ |
| 化学分析与环境检测 | 水样、混合物、色谱柱、检测器与标定样品 | 换一批水样后两个信号峰开始重叠，改变分离条件或加入参照物能否恢复定量能力？ |
| 生命科学与显微成像 | 固定组织切片、荧光标记、光照历史与相机 | 同一视野复拍时信号变弱。怎样安排参照视野和曝光次序，分辨光漂白与照明波动？ |
| 热流体、机械与制造 | 热边界、流道、夹具、载荷与传感器 | 同一个稳态读数背后，系统经历了怎样的动力学？改变哪个边界条件可以查明？ |
| 机器人与精密装配 | 夹爪、工件、接触面、传感器以及装配历史 | 如何用力与位移读数区分工件卡住、夹具偏移和传感器零漂？ |
| 农业与环境科学 | 生长批次、土壤水分、天气、采样点和观测窗口 | 怎样用少量传感器与对照地块区分灌溉变化、环境差异和仪器偏差？ |
| 天文与被动观测 | 目标、观测时段、大气与仪器响应 | 研究者可以改变波段、曝光与观测计划，判断微弱变化来自目标还是观测链 |
| 计算与网络系统 | 工作负载、缓存、队列、拓扑与资源竞争 | 怎样改变激励和采样位置，区分尾延迟来自排队、缓存还是服务本身？ |

这些领域还可以协作。例如材料实验室交出一片有制备历史的膜，光学实验室测其光谱，环境试验台给它一次温度循环，最后回到同一光谱仪复测。薄膜的身份、不可逆变化和测量条件随它走。在天文研究中，可干预的是观测计划。在计算实验中，可直接运行被研究的软件。

## 五、值得研究的创新与保真度

**开放组合。** 装置发布后，独立使用者应能用公开操作设计作者未预置的对照或测法。组件接口应说明可连接对象、输入输出的单位、带宽与量程。以温升实验为例，独立增加一条电测通道，就能估计原先无法从单个读数识别的热阻。

**按实验问题选择保真度。** 同一套装置可以有解析近似、专用数值求解器，以及用实测数据校准的快速模型。对准备执行的干预，先写下要预测的量、工作范围与允许误差。例如，光台可分别报告耦合峰位置的角度误差、功率变化的毫瓦误差及饱和发生的条件。对需要选择工艺的研究，还要看模拟给出的两个方案的优劣顺序，在实测中是否保持。合成实例从实测分布或已说明的物理先验中生成，保留漂移的时间相关性以及共享扰动在多个传感器之间的相关性。

**保真度需要可复核的范围。** 声明“可预测”时写清装置或总体、干预、工况、可观测量、容差和参照测量。容差由要做的科学或工程决定给出。例如两个工艺之间的差只有几个毫瓦，测量本身的不确定度又与这个差相当，就应把两种方案的排序记为尚难分辨。先用一部分工况校准，再在未用于调参的装置、日期或干预条件上检验与声明相符的泛化能力。记录系统性偏差、误差分布和测量不确定度。报告预测区间时同时给出覆盖率和区间宽度。一个合成实验室可以从理论模型起步。公开数据足以支撑哪些结论，就发布到相应范围。[JCGM 测量不确定度指南](https://www.bipm.org/en/doi/10.59161/jcgm100-2008e)

**让模拟与实物共同改进实验。** 当几套模型都能解释历史读数，却对一次可行的操作给出不同预测时，值得看预测差别能否超过测量不确定度，再权衡机时和样品成本。实验室应能先存下各模型的预测，再接收实测，保留偏差及其条件。已有数据可做留出检验，新取得的观测可检验事先作出的预测。需要跨设备推广时，再测量换装置后的重校准成本。研究结果也包括查明某种实验在什么工况下仍需上真机。

已有工作提供了可直接借鉴的做法。卡内基梅隆大学的 AI Science Foundry 提供可远程编程的实体实验设施。FMI 的协同仿真接口允许多个模型各自使用合适的求解器，并在约定时交换输入和输出。Causal Chambers 提供真实装置的干预数据、机理模型及远程接口。TwinLab-Bench 研究 Agent 能否借助实验室记录和计算器自行设计实验。[CMU AI Science Foundry](https://ai-science-foundry.cmu.edu/) · [FMI](https://fmi-standard.org/) · [Causal Chambers](https://pypi.org/project/causalchamber/) · [TwinLab-Bench](https://arxiv.org/abs/2611.26248)

拟议项目把这些能力落实在一间可持续存在、可改造、可独立贡献的实验室里。实验者提出新问题，搭出新配置，先从模型得到预测，再用真实装置作出取舍。模拟中发现的效应可以成为关于自然的假设，独立实测决定该假设在什么范围内成立。对于与实物持续对应的数字孪生，模型也随这些新观测更新。[美国国家科学院等关于数字孪生的研究报告](https://www.nationalacademies.org/read/26894/chapter/10)

## 六、多个环境共同使用时必须约定什么

公共规范只统一会改变其他人实验含义的事项。软件语言、内部数据结构、学科方程、数值算法和仪器型号由领域团队选择。一个装置只需实现它真实拥有的能力。一旦声明支持某种能力，下面相应的行为就应可以实际检验。

| 共同约定 | 开发和运行时的要求 | 发生冲突时怎样处理 |
|---|---|---|
| 对象身份与状态归属 | 样品、设备、实验、操作和结果有稳定标识。同一现场、同一时刻的同一物理量有明确的更新方。命令设定值、仪器回读、模型估计各有来源。分样、加工、合并和转移保留来历 | 两个模型都预测同一温度时可保留两个预测。共同驱动后续实验的温度由指定模型或显式耦合解算给出。取走一份材料只扣减一次 |
| 物理量与接口 | 对外说明量的含义、单位、参考面或坐标系、方向及有效范围。按需声明数组轴、采样间隔、波段、数据缺失和饱和。写明操作前提、耗时、副作用和结果 | 纳米与微米可显式换算并保留来源。计数变成功率需要相应校准。缺少变换时指出缺哪项条件，暂停这次连接 |
| 实验时间与因果 | 记录动作发生、数据采集和结果可读取的时刻。声明时钟来源、采样窗口和必要的同步精度。跨求解器约定通信时点、事件顺序、双向反馈以及步长误差 | 毫秒曝光与秒级温控可以使用不同步长。曝光对相应时间窗的信号积分。晚到的观测按采集时间归档，研究者在它实际到达后才能据此行动 |
| 跨域物理与数值 | 交换边界量时指定接收方怎样使用它。若同时解电、热、力等耦合过程，由领域包给出近似、耦合算法与精度。适用时核对包含源、损耗及边界通量的收支 | 同一束被样品吸收的光功率计作一次热输入。对强反馈，缩小通信步长或联合求解，检验目标观测是否在事先给定的容差内稳定 |
| 观测与数据来源 | 人、脚本和 Agent 的普通实验接口读取现场可取得的信号。每个结果关联运行、动作及采样条件。区分实测、模拟和混合来源，分别记录原始信号与派生分析。混合记录具体到通道或阶段 | 更换分析方法产生新的派生结果。模型估计可以与实测并列显示。历史回放遇到数据未覆盖的干预时，明确返回缺测，或转交标明来源的求解器或真机 |
| 并发与外部设备 | 独立实例各有可写状态。共享真机、夹具或唯一试样的互斥操作，由管理该资源的一方排队或拒绝，并返回占用原因。协作会话识别命令依据的配置版本 | 一个 Agent 正在曝光时，另一个请求换样，按装置声明的物理约束安排次序。支持原位测量的装置可以显式允许并行。真机设备的调度沿用 IOP 或已对接的设备控制器 |
| 断线、重试和恢复 | 长操作先保存操作标识，再据它查询状态与结果。同一标识和参数的重试返回原操作，标识相同但参数改变时返回冲突。记录已完成步骤、未决动作、已产生的数据和真实副作用 | 中途断线后若无法确认加热是否执行，标记结果待确认，用控制器记录或仪器回读尽量查清。现场仍无法判定时，保留未知状态，由实验者选择后续可行的测量。真机上的材料变化留在历史中 |
| 能力、版本与依赖 | 设备或模拟器声明支持的操作、输入与输出、接口和模型版本，以及可选的暂停、快进、分支和真机访问等能力。不同版本的求解器可在独立进程或环境内运行 | 旧会话继续引用原配置。需要新版本时做显式迁移或另开模拟分支，保留对应关系。缺少某个专用依赖时报告受影响的装置，其他已安装装置仍可工作 |

以一片有编号的薄膜为例。制备包交出厚度为 500 nm 的样品，光学包可按 0.5 μm 读取，二者引用同一片膜及同一次厚度测量。样品进入热循环箱后，离线光谱仪的请求要等样品移出。装在箱体上的原位探头可以在热循环中读数。加热期间网络断开时，接手的 Agent 先查询原操作和箱温。研究者若还要一个“未加热”的真机对照，就另取同批试样并记录差异。只有声明支持分支的模拟，才能从同一初态走两条路线。这一个实验同时检验单位、样品身份、占用、时间、恢复和对照的含义。

不同求解器的协同可以参考 FMI 的模型交换和协同仿真约定。适配器按具体模型支持的能力选择方案。对于需要计算双向作用的连接，约定交换数据的格式只是第一步，还要由负责耦合的模型给出数值解和误差。[FMI 协同仿真规范](https://fmi-standard.org/docs/3.0.2/)

## 七、仓库结构与 EnvFoundry 分工

| 拟建目录 | 由它维护的内容 |
|---|---|
| `src/` | 实验室发现与加载，会话、实验时钟、操作调度、状态保存与恢复，观测与原始数据引用 |
| `labs/` | 随仓发布的参考装置。每套包含组件和连接、状态演化、仪器读数、可执行实验、模型假设与实测资料来源 |
| `adapters/` | 对接 IOP、专业求解器、Agent 工具和 Gym 的薄接口。专用物理模型留在所属领域包内 |
| `examples/` | 人与 Agent 都能复做的完整研究，包括改造装置、自选对照、跨会话继续和批量采样 |
| `docs/`、`tests/` | 贡献与使用指南，以及覆盖物理关系、观测范围和状态延续的测试 |

专业团队可以独立维护并发布领域包。一个新包至少提供一套可启动装置、一种能改变现场或采样条件的操作、一项可读取的观测和一个完整实验。作者同时说明参考数据、已知适用范围，以及它能否暂停、恢复、分支或连接实物。大体积数据可由包引用相应数据集。移植到另一台实验设备时，应能沿用实验程序，单独替换设备描述与校准。

在 EnvFoundry 中，**IOP** 负责设备操作和实体实验协调，**Optics–Photonics AI Lab** 提供光学软件与求解能力，**SeedEnv** 可发现和准备依赖。本项目负责一次实验中多个组件如何形成同一个现场，现场如何演化，操作产生什么可见结果。**Verifiable Agent Gym** 用外部任务包接入相同装置，**Data Engineering** 管理轨迹与数据发布，**AI Evaluation** 比较相同条件下的模型、Harness 与策略。已有 IOP 光台包含预热、漂移、耦合、饱和和零点变化，适合作为首台装置的起点。[环境目录](https://github.com/EnvFoundry/environments) · [IOP 光台](https://github.com/EnvFoundry/IOP/tree/main/examples/iop/optical-bench) · [Gym 扩展接口](https://github.com/EnvFoundry/Verifiable-Agent-Gym/blob/main/docs/task-packages.md)

项目之间交接的是可使用的结果。真机返回 IOP 操作标识和读数，实验室用它们更新该次实验的记录和对样品状态的估计。光学工具接收带边界条件的器件模型，返回数值结果。Gym 只为选定问题增加任务和评分。训练回合结束时，只释放这一回合拥有的资源。长期实验现场、真机队列和其他研究者的会话由各自的所有者继续维护。

建议首版以 Python 提供科学模型和直接接口，以 CLI 或 MCP 暴露装置可用操作。操作返回带单位、实验时间、来源及运行标识的结果。长采集先返回操作标识，再取波形或图像。训练程序可在求解器旁批量运行独立实例。持久实验元数据可使用 SQL，原始大数组存文件或对象存储。远程访问可使用 TypeScript 客户端连接持久会话。真机按实际时钟执行，持续采集可以在客户端断线后独立运行。模拟可以按装置能力快进、暂停或复制。高吞吐的事件调度或采样部分可按实测瓶颈采用 Rust。

## 八、开放科研、基准、评测和 RL 各看什么结果

选题先问三个具体问题。解决它会改变哪项科学判断或工程决策？现有方法在哪里分不清解释、浪费机时或失去精度？有什么独立方法判断新方案更好？值得长期维护的难度可以来自部分可观测、昂贵或不可逆的实验、跨时间尺度的漂移、不同个体和相互矛盾的设计目标。例如材料团队要在有限剩余膜层内修正光谱偏差，电池团队要在有限测试时间内选出值得继续跟踪的电芯。它们都能产生下一项真实决策。

以候选基准为例，光学薄膜工艺可让 Agent 依据中途光谱修正余下膜层，在一个新批次比较目标波段内的实际透射偏差和报废样片数。电池筛选可让它在同一测试时长内自行选择短测量，再用留出电芯后来取得的完整循环数据检查寿命排序。精密装配可在换批工件上比较一次装配成功率、最大接触力和节拍。这些是拟开发的问题。实际批次、任务预算、基线和容差需要领域团队据实确定。

| 用途 | 公布的实验条件 | 判断成果的方式 |
|---|---|---|
| 开放实验与前沿研究 | 可操作的设备与测量、可用时间和材料、已经知道的条件。研究者自行提出假设、改变装置、确定下一步 | 一项独立设计的干预能否使两个解释给出不同预测，或让新器件达到有单位的目标。结论可以是排除一条路线。涉及现实新现象时，保留事先预测并取得独立观测 |
| 建立 benchmark 与比较 Agent | 任务包定义问题、允许的观察和操作、预算、终止条件、对照方法。固定用于比较的装置与任务版本，按设备、批次、日期或干预划分开发与保留条件 | 在相当的机时、试样和信息条件下，与简单策略及适用的领域方法比较。报告每类工况的误差或成功率、试验次数、失败和不确定度。保留工况与评分器由评测侧持有 |
| 强化学习与数据工程 | 模拟实例独立，明确哪些初始条件可采样、哪些参数有实测依据，哪些是用于探索的先验。训练包描述奖励和外部预算，关联操作、观测、原始数据与结束原因 | 检查策略在未见个体或工况上是否仍有效。区分任务自身终止与外部时间或预算截断。对外公布并行吞吐量时，同时给出硬件、模型精度和单步代表的实验时间 |
| 长时间自主探索 | 实验时钟持续推进。后台采集、样品变化、漂移和资源占用可跨多次决策。研究者或 Agent 换班时能读取装置配置、原始资料、尚在执行的操作和已检验的假设 | 中断后能从同一现场继续。遇到漂移能重新测量而非沿用过期结果。记录得到新结论所用的实际机时、材料和重校准成本，以及下一位研究者能否接着做 |

环境自身的预测误差与研究者的任务成绩分开报告。两个 Agent 在同一错误光谱模型上得到高分，只能说明它们掌握了该模型。实验室用留出的实测数据检验光谱模型。任务包再用相同资源比较研究者的实验方法。开放科研可保留失败尝试和无确定答案的研究记录。交互记录进入数据集前，明确来源、可复用范围和划分。来自同一台设备或同一条轨迹的近似副本按研究目标分组，避免同源信息跨过训练与评测边界。[Gymnasium 环境接口](https://gymnasium.farama.org/api/env/)

## 九、怎样加入领域、升级版本和持续运行

**共同的发布起点。** 一个领域包交付可安装的装置、操作与观测说明、适用范围和依赖版本。用一项完整实验，从新环境启动到得到原始读数与可解释的结果。外部贡献者能够复做，并在已有元件上改变一个条件、看见相应后果。容差、参照结果、参考数据来源、数据和求解器的使用条件随包发布。暂无实测的理论模型可以标明依据后发布，并说明将来哪组实测能区分候选模型。

**特定能力有特定承诺。** 声明可恢复的模拟器，须保存足以决定未来演化的状态，包括样品历史、求解器状态、随机数状态、待处理事件与模型版本。用“不中断”与“恢复后继续”的同一操作序列比较。确定性后端可比较逐步结果，数值或并行后端按声明的容差或统计性质比较。声明可分支时，一个分支的写入应不影响另一个。真机的接续依靠当时的实际读数、样品身份和设备运行记录。声明数字孪生时，还要给出实物身份、更新的触发条件和时间、独立预测结果，以及预测怎样用于下一次实物实验。

**接口演进与多人贡献。** 领域维护者负责模型、适用范围和科学参照，公共运行系统的维护者负责跨包约定，Gym 和评测维护者负责任务及评分。一项新能力先在所属领域实现。遇到第二个不同领域的实际需求时，再考虑把共同部分提升到公共接口。改动动作、读数、单位、精度或评分含义时，发布新版本并留下旧版读取方式或可执行迁移示例。在一条历史轨迹和一项跨包实验上说明变更的影响。进行中的实验固定其依赖，升级产生明确的后续记录。维护者能根据真实使用的问题改进模型，其他团队仍能复算早期结果。

**基准怎样保持研究价值。** 保留一组版本固定的参照实验，用于比较方法随时间的变化。新装置、新批次及真实研究中新出现的难题进入单独版本，并设置独立保留条件。引入更强的领域方法、修改评分或修正环境物理时，在同版条件下重跑有代表性的基线，说明原先哪些研究结论发生变化。这样既看得见一年前的进步，也能发现今天的方法在什么问题上仍然失效。

**云端承载。** 本地研究、远程访问和批量训练调用同一组有物理含义的操作。跨进程使用明确的数据格式和版本，可以隔离冲突的软件依赖。不同用户各自持有会话和实验资源的访问权限，大型原始数据以持久引用传递。工作进程重启时，恢复已记录的任务、已写入的数据及其对应关系。设备控制器执行其物理限位和访问约束，训练接入真机需要选择相应的设备与机时。对外承诺支持的负载，要在声明的硬件和工作量下测出并行实例数、排队或操作延迟与恢复行为。领域包可以在本地先发布，再据实际需求接入云端。

## 十、首期交付与后续发展

| 交付目标 | 交付物 | 达到什么程度算完成 |
|---|---|---|
| 首个可持续实验室 | 基于 IOP 现有模型的光纤耦合台，具有明确的实验时间、公开观测与完整模拟状态 | Agent 自行设计测量，中断后从同一模拟状态继续，并分支比较两条操作路线对功率计与相机的影响。一位独立使用者能用原装置回答一个未预设的问题 |
| 第二个独立领域与训练入口 | 带公开干预数据的风洞等热流体装置、外部领域包示例、Gym 接口与轨迹导出 | 第二领域复用公共会话与记录接口。在留出的实测工况上比较预测与观测。用同一装置开展开放实验、并行训练，并在独立装置实例上评测 |
| 首个持续更新的实物孪生 | 某台有具体身份的实物、对应模型、校准数据及历次预测记录 | 在未参与校准的条件下先提交预测，再取得实测。新实测更新模型并用于选择下一次实验。公布带单位的误差、预测区间覆盖率及宽度，并同简单模型或直接真机搜索比较。在相同科学目标下计入校准和正式实验占用的全部真机时间 |
| 多团队云端运行 | 隔离的模拟实例、可共享的协作会话、按物理约束协调的设备队列和持久原始数据 | 两个客户端同时申请同一设备，执行顺序符合装置约定。令工作进程在长采集中途重启，再次查询原操作能看见实际进度或明确的未知状态。检查没有重复施加不可逆动作，原始结果仍与正确的样品和版本对应 |

首期需要熟悉装置的实验人员、能实现科学模型和接口的工程人员，以及一位独立设计实验的使用者。早期可用本地计算和公开数据跑通前两类工作。实物孪生与云端承载可以并行建设，前者需要具体装置、校准数据和机时，后者需要在可说明的并发负载下运行。不可逆实物实验使用同批独立试样做对照，记录样品间差异。历史实测、模拟读数和后续新测量分别标注，方便研究和训练各取所需。

立项的首个有说服力的结果，是一位没有参与编写装置模型的研究者或 Agent，能在里面提出一个新问题、搭出有区分能力的实验，得到原始观测，并清楚说明由此学到了什么。随着不同学科贡献装置，并用真实世界的测量约束各自的模型，这个仓库才会逐步成长为可长期使用的科研基础设施。
